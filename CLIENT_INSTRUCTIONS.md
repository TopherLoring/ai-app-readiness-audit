# AI-Built Application Readiness Audit — Client Instructions

**What this is**  
A fixed-scope launch-readiness check for applications built with AI coding tools (Cursor, Claude, Lovable, Bolt, v0, etc.). We run a structured smoke-test suite, review basic configuration and common failure patterns, and deliver a prioritized readiness report.

**Price range**  
$500 – $750 depending on app size and access. Confirmed before work begins.

---

### What you need to provide

1. **Application URL (required)**  
   Staging or production URL that we can reach. Password-protected staging is fine if you share access.

2. **Optional but helpful**  
   - Link to the GitHub (or similar) repository (read-only)  
   - Short description of the primary user journey  
   - Any known broken areas or upcoming launch date

3. **Access**  
   No admin credentials required for the base audit. If you want deeper checks (authenticated flows), provide a test account.

---

### What you will receive

- Prioritized readiness report (Critical → Low)
- Findings on broken routes, form/validation gaps, basic auth surface, obvious secret exposure, and common AI-app failure patterns
- Concrete fix recommendations with effort estimates
- Short walkthrough (Loom or call)
- Optional separate quote for remediation help

---

### Process & timeline

| Step | What happens | Typical time |
|------|--------------|--------------|
| 1 | You send URL + brief context | — |
| 2 | Scope & firm price confirmation | Same day |
| 3 | Audit + report | 1–2 business days |
| 4 | Walkthrough | Included |

Active diagnostic time is normally ≤ 3 hours for a tightly scoped app.

---

### In scope

- Smoke tests of key routes
- Basic HTML/form/auth surface review
- Common security-hygiene checks (not a penetration test)
- Launch-readiness recommendations

### Out of scope

- Full security audit or penetration test
- Performance / load testing
- Ongoing monitoring
- Guarantee that the application is “secure” or “bug-free”
- Large feature builds (available separately)

---

### Important positioning

This is a **readiness assessment**, not a comprehensive security audit.  
We do **not** certify that an application is secure.

Reply with:
